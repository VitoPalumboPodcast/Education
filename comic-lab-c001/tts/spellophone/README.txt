Spellophone 0.2.1 / eSpeak NG

dialogues. The files in this directory were obtained from:

https://www.npmjs.com/package/@spelling-creator/spellophone/v/0.2.1

- wasm/espeak-ng.js
- wasm/espeak-ng.wasm
- espeak-ng-data/manifest.json
- espeak-ng-data/core.bin.gz
- dictionaries for English, Italian, French and Latin
